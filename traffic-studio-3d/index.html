Grid Control

A microscopic traffic simulation you can rebuild while it runs, now in 3D: every vehicle runs an Intelligent Driver Model longitudinal controller, changes lanes on a MOBIL-style incentive check, and follows a Dijkstra route it will re-plan when the network slows down. Signals run a NEMA-style ring with optional actuation and coordination.
